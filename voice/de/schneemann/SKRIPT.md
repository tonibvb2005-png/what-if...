# Sprechtexte: Bommel und der Schneemann

Eine Datei pro Zeile, z. B. `voice/de/schneemann/s1a.mp3`. Stimmen: Erzähler/in, Bommel, Kiki.
Für „Bommel & Kiki“ beide Stimmen zusammen (oder nacheinander) in eine Datei.

| Datei | Wer | Text |
|---|---|---|
| `s1a` | Erzähler/in | Es hat die ganze Nacht geschneit. |
| `s1b` | Bommel | Juhu! Schnee! Alles ist weiß! |
| `s2a` | Bommel | Ich baue einen Schneemann! |
| `s2b` | Erzähler/in | Bommel rollt eine riesige Kugel. |
| `s2c` | Erzähler/in | Und noch eine kleinere Kugel. |
| `s3a` | Bommel | Hau ruck! |
| `s3b` | Bommel | Uff ... die Kugel ist viel zu schwer. |
| `s4a` | Kiki | Hallo Bommel! Soll ich dir helfen? |
| `s4b` | Bommel | Oh ja, bitte! Danke, Kiki! |
| `s5a` | Bommel & Kiki | Eins ... zwei ... drei ... HOCH! |
| `s5b` | Erzähler/in | Und oben drauf kommt der Kopf. |
| `s6a` | Kiki | Ich hole eine Karotte für die Nase! |
| `s6b` | Bommel | Und er bekommt meinen Schal! |
| `s6c` | Bommel & Kiki | Zusammen geht's viel leichter! |
| `s7a` | Erzähler/in | Was baust du gern im Schnee? |
