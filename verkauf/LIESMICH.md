# Verkaufsseite Horror-Roulette-Kit

- `index.html` – fertige Seite zum Hochladen (z. B. Netlify Drop, GitHub Pages, eigener Webspace). Bilder sind eingebettet, es ist nur diese eine Datei.
- `vorlage.html` – Quelle mit Platzhaltern; `bilder/` – die Standbilder aus Folge 5.

Vor dem Veröffentlichen in `index.html` ersetzen:
- `href="#kaufen"` beim Button „Jetzt für 15 € holen“ → dein Link von Gumroad / Lemon Squeezy
- `[Zahlungsanbieter]` → Name des Anbieters
- die drei `href="#"` im Fußbereich → Links zu Impressum, Datenschutz, Widerruf
