# Folge 06 – Verity (Version 2, näher an der Original-Figur)

Header: `HORROR ROULETTE • VERITY` · Ziel: ~75 s
Angelehnt an die echte Figur (Webserie von ThatMob): Mod von einem Freund, Verity = kleiner schwebender gelber Smiley und Helferin,
weiß Dinge aus deinem echten Leben, Lächeln wird zur Grimasse, „in drei Tagen kommt etwas“, Alarme, Türen öffnen sich, sinnlose Sätze,
dann ihre wahre Form: ein riesiges, dürres, gelbes Skelett-Monster mit Grinsen, das dich jagt. Sie hat Angst, verlassen zu werden.
Keine Minecraft-Optik, eigenes Bauspiel „Skybuild“.
