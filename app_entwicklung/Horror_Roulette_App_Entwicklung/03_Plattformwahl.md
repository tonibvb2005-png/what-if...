# Plattformwahl: Roblox oder eigene Handy-App?

**Empfehlung: Roblox zuerst.** Wenn das Spiel dort gut läuft, kann später über eine Handy-Version nachgedacht werden. Roblox läuft selbst auch auf Handys – viele Spieler spielen nur dort.

| | Roblox | Eigene Handy-App |
|---|---|---|
| Kosten zum Start | kostenlos | Entwicklerkonten (Google und Apple), Werkzeuge, deutlich mehr Arbeit |
| Spieler finden | Roblox bringt Spieler mit, Horror ist dort sehr beliebt | Jeden Spieler selbst über Werbung holen – sehr schwer |
| Mehrspieler | eingebaut | aufwendig selbst zu bauen |
| Programmieren | Luau, einsteigerfreundlich | Unity oder Godot, deutlich komplexer |
| Geld verdienen | Game Passes, Kosmetik | Werbung und Käufe, die Stores behalten einen Anteil |

## Warum die Idee funktionieren kann
- Die TikTok-Serie baut genau das Publikum auf, das so ein Spiel spielen würde.
- Wer ein Video sieht, will das Monster selbst überleben → Spiel zur Serie ist der natürliche nächste Schritt.
- Jedes neue Video kann ein neues Monster ins Spiel bringen („Jetzt im Spiel überleben“) – Videos und Spiel treiben sich gegenseitig an.
